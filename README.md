# Tallyer

An open-source score/tally keeper for any kind of score-based game.

Plan:

* Audit log of who changes whos points when
* Scoreboard view for big screens
* Manage the score on any device
* Presets for common games (e.g. starting Dart games at 301/501 and decreasing scores)
* Password protection for game room, and each player
* Optional buzzers for each player
